---
title: "OpenAgents API: AI Intent Generation and Risk Assessment"
sidebarTitle: "Agents"
description: "REST endpoints that use QVAC on-device AI to draft trade and offer intents from plain language and to assess an intent's risk before you act on it."
---

OpenAgents exposes QVAC — Tether's local AI runtime — for trade assistance. Inference runs on the Sails node itself with a quantized Llama 3.2 1B model (llama.cpp); no cloud AI service is involved. Each endpoint is a single model call: it drafts a structured intent or assesses one, once. None of them negotiate with a counterparty or keep state between calls.

<Note>
  All three endpoints require a session and share a stricter rate limit, because each call runs real model inference. They never persist anything or act on your behalf — always review the output before using it.
</Note>

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/agents/generate-trade-intent` | Draft a buyer's trade intent from a goal |
| POST | `/v1/agents/generate-offer-intent` | Draft a seller's offer from a goal |
| POST | `/v1/agents/assess-intent-risk` | Assess an intent's risk |

---

## Generate a trade intent

**`POST /v1/agents/generate-trade-intent`**

<ParamField body="goal" type="string" required>
  Plain-language description of what you want to buy (1–2,000 characters). Mention asset, amount, payment method, and price limits.
</ParamField>

```json Request
{ "goal": "Buy 0.01 BTC using PIX, max $46,000" }
```

```json Response (data)
{
  "asset": "BTC",
  "side": "BUY",
  "maxValue": "46000",
  "minValue": "100",
  "currency": "USD",
  "fiatMethod": "PIX"
}
```

Fields the model can't infer from your goal may be missing. After reviewing the values, you can use them as the payload of a `TradeIntent` in `POST /v1/intents` (see [Intents](/concepts/intents)).

---

## Generate an offer intent

**`POST /v1/agents/generate-offer-intent`**

<ParamField body="goal" type="string" required>
  Plain-language description of what you want to sell (1–2,000 characters).
</ParamField>

```json Request
{ "goal": "Sell up to 1 BTC accepting bank transfer" }
```

```json Response (data)
{
  "asset": "BTC",
  "side": "SELL",
  "minAmount": "0.001",
  "maxAmount": "1.0",
  "paymentMethod": "BANK_TRANSFER"
}
```

Review the draft and add your price before publishing it with `POST /v1/liquidity/offers`.

## Assess an intent's risk

**`POST /v1/agents/assess-intent-risk`**

The assessment is based only on the intent you send — it doesn't look up a counterparty's reputation or history.

<ParamField body="asset" type="string" required>
  `BTC`, `LN_BTC`, `LIQUID_BTC`, `RSK_BTC`, `USDT_ERC20`, `USDT_TRC20`, `USDT_LIQUID`, `USDT_LIGHTNING`, `SPARK`, or `STACKS`.
</ParamField>

<ParamField body="side" type="string" required>
  `BUY` or `SELL`.
</ParamField>

<ParamField body="maxValue" type="string">
  Maximum value, as a decimal string.
</ParamField>

<ParamField body="minValue" type="string">
  Minimum value, as a decimal string.
</ParamField>

<ParamField body="currency" type="string">
  `BRL`, `USD`, `EUR`, `GBP`, `ARS`, `MXN`, `NGN`, or `INR`.
</ParamField>

<ParamField body="fiatMethod" type="string">
  `PIX`, `TED`, `BANK_TRANSFER`, `CRYPTO_DIRECT`, `LIGHTNING_DIRECT`, `CASH`, or `OTHER`.
</ParamField>

```json Response (data)
{
  "risk": "low",
  "reasoning": "Moderate amount on an instant, widely used payment rail.",
  "recommendation": "proceed"
}
```

<ResponseField name="risk" type="string">
  `low`, `medium`, or `high`.
</ResponseField>

<ResponseField name="reasoning" type="string">
  The model's explanation.
</ResponseField>

<ResponseField name="recommendation" type="string">
  `proceed`, `hold`, or `reject`.
</ResponseField>

<Warning>
  The assessment is advisory output from a small local model. It can be wrong — treat it as one input to your decision, never as a guarantee.
</Warning>
